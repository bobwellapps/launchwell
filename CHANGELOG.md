# Changelog

## 1.2.0

- New: update notifications for GitHub installs. An Update button in the menu and a dot on the panel button when a newer release is out (can be turned off)
- Fixed: resizing by dragging the edges now uses the window manager, so it's smooth instead of flickering and jumping
- Fixed: A–Z letter headings showed the wrong letters while scrolling; they now always match the apps below them, and accented names (É, Ö…) sit under their plain letter

## 1.1.0: first public release

- Kickoff-style layout with classic Plasma 5 colour category icons, or mono
- Panel button: classic colour logo, new Plasma 6 logo, or a custom icon
- Search bar, Power/Session buttons and Settings button can each be placed in several spots
- List or grid views, letter headings with A–Z jump, category list left or right
- Menu opens centred above the taskbar by default, with full position controls
- Resize the menu by dragging its edges
- Backgrounds: Plasma theme, custom colour, or your own picture with blur and darkening
- Opening, closing, category-switch, cascade and hover animations
- Apps and settings windows open on the monitor the menu was opened on
